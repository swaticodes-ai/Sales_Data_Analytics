# Sales Data Analytics using Python

## 📊 Project Overview

This project analyzes sales data using Python to find useful business insights from a sales dataset.

The project uses **Pandas** for data analysis and **Matplotlib** for data visualization.

## 🎯 Objectives

* Calculate total sales
* Find the best-selling product
* Identify the product generating the highest revenue
* Analyze sales by region
* Analyze sales by category
* Analyze monthly sales trends
* Check for missing values
* Create charts to visualize the results

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* VS Code
* Git & GitHub

## 📁 Dataset

The dataset contains the following information:

* Date
* Product
* Category
* Quantity
* Price
* Region

## 🔍 Analysis Performed

The project calculates:

* Total Sales
* Quantity Sold by Product
* Total Sales by Region
* Total Revenue by Product
* Monthly Sales
* Sales by Category
* Best-Selling Product
* Highest Revenue Product
* Best-Performing Region
* Best-Performing Category
* Missing Values

## 📈 Visualizations

The project creates charts for:

1. Quantity Sold by Product
2. Total Sales by Region
3. Total Revenue by Product
4. Monthly Sales Trend

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the Python file:

```bash
python analysis.py
```

## 📌 Conclusion

This project demonstrates basic data analytics skills using Python. It shows how raw sales data can be cleaned, analyzed and visualized to identify useful business insights.
